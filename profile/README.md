**READY.** Type-in BASIC programs from the Commodore 64 books of the 1980s: typed into a modern editor, checked line by line, built into real `.prg` files, run in VICE and explained on [c64n.blogspot.com](https://c64n.blogspot.com).

```
    **** COMMODORE 64 BASIC V2 ****

 64K RAM SYSTEM  38911 BASIC BYTES FREE

READY.
LOAD"C64 CODING",8,1

SEARCHING FOR C64 CODING
LOADING
READY.
RUN
```
